# Day 2 UI 精簡：改了什麼、拿掉什麼（2026-10-24）

規格：主目錄 research/21-day2-ui-spec.md。預覽：https://preview.taipei-tree-twin.pages.dev/

## 改了
1. 左上圖層 → 「用途按鈕」，每角色最多 4 顆，同時只開一顆；每顆有圖示＋短名＋一行預告。按下去地圖飛到代表性地點（用真實資料算最密的一格），黃框跳一句結果提示，圖例跟著出現。再按一次關掉。
   - 民眾：多久沒人拍、哪裡還能種、企業認養、東門茄苳
   - 主管機關：先去看哪棵（複查優先序）、人多沒樹蔭、哪裡還能種
   - 企業：企業認養、人多沒樹蔭
   - 規劃：哪裡還能種、人多沒樹蔭、不再新植、移動植栽
   - 首長：先去看哪棵、人多沒樹蔭、哪裡還能種、東門茄苳
   - 廠商：不放按鈕（第一眼是查核示範）
   - 按鈕依功能開關自動隱藏，所以實際顆數可能少於設定。
2. 每個角色進站第一眼：重點卡（一個數字＋一句話＋主要按鈕＋次要連結），取代原本自動彈出的首頁側欄。
3. 企業認養、施工查核改成 3 步引導故事（#/story/esg、#/story/vendor）：開頭說是誰（虛構）、哪棵樹、示範什麼；步驟條 1/3 2/3 3/3 加「下一步」；結尾說解決了什麼。全程標模擬。
4. 認養／贊助的樹：樹頁顯示企業 logo＋一則示意新聞連結（虛構，連到站內 #/news/<企業>，不連外部網站）。
5. 單棵樹頁：決策功能只留一行「延伸分析（獨立頁）」連結（樹冠負債、工程衝突預警、廠商履約、民意熱點、權責地圖）。

## 拿掉（從主地圖與側欄）
- 樹種篩選下拉（搜尋框仍可搜樹種）
- 「我附近 500 公尺」按鈕 → 移到民眾重點卡的主要按鈕
- 兩顆示範按鈕 → 東門茄苳變成用途按鈕；富民公園改從「公開紀錄」看
- 行道樹／公園樹開關按鈕（兩種樹常駐顯示）
- 11 個決策功能的地圖圖層按鈕與樹頁大區塊：樹冠負債、存量帳、首長儀表板、樹蔭公平、承諾追蹤、民意熱點、權責地圖（含點地圖空白處的彈窗）、公開欄位清單、工程衝突預警、廠商履約、逐時曝曬。改成只從「功能」目錄或導覽進獨立頁；它們的地圖疊加只在自己的頁面上打開。
- 角色切換時自動彈出的首頁側欄（管理總覽、認養總覽、規劃總覽仍在上方導覽）
